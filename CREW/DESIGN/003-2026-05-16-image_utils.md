Summary:
image_utils.py contains image processing helpers: overlay_grid, crop_from_annotations, process_images and color utilities. It mixes I/O, image transformations, and small utility helpers.

Recommendations:
1. Split responsibilities: separate I/O (file discovery, reading/writing) from pure image transforms. Create an image_processing.py (pure) and image_io.py (disk operations).
2. Add strict typing for inputs/outputs (Path vs str, Tuple[int,int]) and return lists of Path objects.
3. Make error handling explicit: raise exceptions for unrecoverable errors or return Result objects; avoid silent None returns.
4. Consolidate save kwargs builder and document supported formats; prefer Pillow options explicitly.
5. Add unit tests using small in-memory images (BytesIO) to avoid filesystem flakiness.
6. Ensure PEP8 compliance and consistent naming (snake_case) across functions (some existing CamelCase wrappers exist; deprecate them).
7. Document performance expectations and memory usage for large batches.
