Summary:
Crew.py is the top-level launcher. It configures logging, ensures dependencies, builds CLI, and starts the GUI. A few behaviors (auto-installing packages, immediate heavy imports) make testing and packaging harder.

Recommendations:
1. Move auto-install logic into a separate bootstrap/install helper invoked explicitly, not during normal startup.
2. Keep main() lightweight: parse args, set config/logging, call explicit startup helpers.
3. Prefer explicit dependency checks and clear user messaging rather than attempting to pip-install dependencies automatically.
4. Add unit tests for main CLI flow using monkeypatch for imports and temporary paths.
5. Document expected environment variables (CREW_INPUT_DIR, CREW_OUTPUT_DIR) and provide a small example config.json.
6. Enforce PEP8 and run ruff/black formatting.
