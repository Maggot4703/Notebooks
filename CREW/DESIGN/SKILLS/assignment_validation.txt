SKILL: Assignment Validation

Purpose:
- Ensure that all agent assignments meet mission requirements and agent qualifications.

Process:
1. Review mission requirements and required roles.
2. Cross-check agent skills, certifications, and availability.
3. Validate that each assignment matches the required skill set.
4. Flag any mismatches or gaps for review.
5. Document validation results in the assignment log.

Inputs:
- Mission requirements document
- Agent skill profiles

Outputs:
- Assignment validation report

Error Handling:
- If a mismatch is found, notify Crew Manager Agent and propose alternatives.
