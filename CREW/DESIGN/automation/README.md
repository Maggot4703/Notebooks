# Automation Folder

This folder contains scripts for automating workflows described in PLANS, SKILLS, and AGENTS. Each script should:
- Read from relevant CSV/Markdown files
- Perform validation, assignment, or deployment
- Log actions/results to NOTEBOOKS/notebooks.txt

## Example Scripts
- crew_assignment_automation.py: Automates crew assignment and validation
- npc_assignment_automation.py: Automates NPC assignment
- user_management_automation.py: Automates user permission assignment
- web_deployment_automation.py: Placeholder for web deployment automation
