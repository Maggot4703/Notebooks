# CREW System Folder Overview

## Crew/
Main application codebase. Contains core modules, CLI/GUI entry points, configuration, data/database management, event and state handling, business logic, TTS, authentication, error handling, and utilities. Subfolders for scripts, usage, input/output, data, and tests. This is the heart of the CREW system.

## data/
Intended for persistent or runtime data files used by CREW. (Currently empty.)

## DESIGN/
Design documentation, plans, and specifications. Contains design.txt and subfolders for agents, jobs, notebooks, plans, rules, and skills. Central for all design and planning documents.

## input/
For input files to be processed by CREW. (Currently empty.)

## output/
For output files generated by CREW. (Currently empty.)

## src/
Source code for CREW-related skills and modular/plugin features. Contains skill demo implementations.

## tests/
Automated tests for CREW modules and features. Includes pytest config, test scripts for core modules, and test logs. Ensures system reliability.

## xBACKUP/
Versioned backups of CREW data and configurations, organized by numbered subfolders. May include backup design docs.

## XCrew/
Experimental or backup copy of the main CREW folder. Mirrors main structure for safe development or refactoring.

## xDESIGN/
Backup or experimental design documentation. Mirrors DESIGN folder for design iteration and backup.

# Sample End-to-End Automation/Validation Workflow: Automated Crew Assignment & Readiness Check

**1. Input Collection**
- Gather mission requirements (roles, skills needed).
- Load agent profiles from skills_db.csv (skills, certifications).
- Load training logs and crew_template_v2.md (role requirements).

**2. Assignment Validation (Automated)**
- For each required role:
  - Find agents with matching skills/certifications.
  - Use logic from SKILLS/assignment_validation.txt:
    - If multiple agents qualify, select based on experience or availability.
    - If no agent qualifies, flag for review and notify Crew Manager.
- Assign agents to roles and record assignments.

**3. Readiness Review (Automated)**
- For each assigned agent:
  - Check training log for up-to-date training.
  - Verify certifications and health status.
  - Use logic from SKILLS/readiness_review.txt:
    - If any readiness criteria fail, flag for corrective action.
- Compile readiness report.

**4. Logging & Notification**
- Log all assignments and readiness results in NOTEBOOKS/notebooks.txt.
- Update crew roster and readiness report files.
- Send assignment notifications (log to assignment_emails.log).

**5. Review & Exception Handling**
- If any assignment or readiness validation fails:
  - Notify responsible agents (Crew Manager, Designer).
  - Propose alternatives or corrective actions.
- Document all exceptions and resolutions.

---
**Example Pseudocode:**
```
for role in required_roles:
    candidates = find_agents_with_skills(role, skills_db)
    if not candidates:
        log_issue(f"No qualified agent for {role}")
        notify_manager(role)
        continue
    selected = select_best_candidate(candidates)
    assign_role(selected, role)
    log_assignment(selected, role)

for agent in assigned_agents:
    if not check_training(agent, training_log):
        log_issue(f"{agent} missing training")
        flag_for_action(agent)
    if not check_certification(agent, crew_template):
        log_issue(f"{agent} missing certification")
        flag_for_action(agent)
    log_readiness(agent)

write_roster(assigned_agents)
write_readiness_report(assigned_agents)
send_notifications(assigned_agents)
```

**Files/Modules Involved:**

- SKILLS/assignment_validation.txt, SKILLS/readiness_review.txt
- NOTEBOOKS/notebooks.txt, assignment_emails.log
- Crew Manager app scripts (Crew.py, etc.)

This workflow ensures all assignments are validated, readiness is checked, and results are logged and communicated—fully automating the core crew management process.

# Recommended CREW System Feature Roadmap (2026)

## 1. Automated Role Assignment
- Add logic to suggest or auto-assign agents to roles based on skills, certifications, and availability.
- Integrate with assignment_validation skill and update assignment logic in Crew.py.

## 2. Agent Availability Tracking
- Add an 'availability' field to skills_db.csv (Active, On Leave, Injured, etc.).
- Update assignment logic to filter out unavailable agents.

## 3. Skill Gap Analysis
- Implement a report that lists missing skills/certifications for each required role.
- Suggest training or recruitment for uncovered roles.

## 4. Training Scheduler
- Add a module to recommend or schedule training for agents missing required certifications.
- Log scheduled/completed training in training_log.csv.

## 5. GUI Enhancements
- Add dashboards for crew status, assignment visualization, and quick-edit features.
- Show assignment history and readiness at a glance.

## 6. Assignment History Log
- Track and display historical assignments and changes for auditability.
- Store in a new assignment_history.csv or similar file.

## 7. Export/Import
- Allow exporting crew rosters and logs to CSV/Excel.
- Support importing updates from external files.

## 8. Notifications/Alerts
- Warn if a role cannot be filled, or if certifications are expiring soon.
- Log alerts and optionally send email notifications.

## 9. Role Rotation/Randomizer
- Optionally rotate assignments to ensure fair distribution of duties.
- Add a toggle in the GUI for this feature.

## 10. API Integration
- Provide a REST API for external systems to query or update crew data.
- Document endpoints and authentication.
