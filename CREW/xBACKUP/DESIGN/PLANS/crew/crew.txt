

PLAN: Crew Assignment

Objective:
- Assign agents to crew roles and ensure readiness for operations.

Steps:
1. Identify crew requirements for the mission.
2. Select agents based on required skills (see SKILLS/assignment_validation.txt).
3. Assign agents to specific roles and confirm acceptance.
4. Validate crew readiness (training, equipment, health) using SKILLS/readiness_review.txt.
5. Log assignments and status in NOTEBOOKS/notebooks.txt.

Inputs:
- Mission requirements document
- Agent skill profiles (skills_db.csv)
- Training log (training_log.csv)
- Crew template (crew_template_v2.md)

Outputs:
- Updated crew roster (crew_roster_0426.csv)
- Readiness report (readiness_report_0426.md)
- Assignment notifications (assignment_emails.log)

Responsible Agents:
- Crew Manager Agent
- Designer Agent

Notes:
- Review assignments weekly or after any major event.
- Follow RULES/always.txt, RULES/never.txt, RULES/sometimes.txt.

Automation & Documentation:
- Automate validation and readiness review using scripts and referenced templates.
- Document all steps and outcomes in NOTEBOOKS/notebooks.txt.
