# Batch OCR Counters Skill

This folder contains the batch-ocr-counters skill for automating the detection and OCR of 200x100px counter images in all PDFs in a directory, using the ocr-pic skill for classification and text extraction.

## Files
- `SKILL.md` — Skill documentation and usage
- `batch_ocr_counters.py` — Main script for batch processing

## Usage
See SKILL.md for full instructions and requirements.
